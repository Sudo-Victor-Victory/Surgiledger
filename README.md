# What is SurgiLedger

SurgiLedger is an event-driven healthcare coordination platform designed to help providers, facilities, and payers coordinate administrative workflows such as prior authorization.

The platform maintains a shared, auditable record of what happened, when it happened, who is responsible for the next step, and what information is required to move a workflow forward.

The initial MVP focuses on building the underlying workflow and event infrastructure needed to make these processes more transparent and measurable.



# Goals
## Core Workflow Infrastructure (CWI)
Allows us to represent and faciliate coordination for healthcare and adminstrative workflows
- Episodes, Events -> Status -> Participants -> Tasks -> Timeline -> Metrics
## Healthcare Workflows (HW)
Creates a high-level capability ontop of the workflow infrastructure
- Prior Authorization -> Documents -> Notificaitons -> FHIR/X12 integrations 
## User Experience
Create an intuitive and visually appealing UI to make complex administrative workflows easy to understand & coordinate across organizations.
